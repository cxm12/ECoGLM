ECoGLM

ECoGLM is a Python-based research project designed to reproduce the experimental results presented in our paper "Bioelectrical Information Theory-Driven Neural Transcoder: Enabling Communication Between Brain and AI".

📥 Installation and Setup

To get started, please download the required model checkpoints and data files. You can obtain these files from the following Baidu Wangpan link:

Download Link: https://pan.baidu.com/s/10iBgJdk1OS4-gBP-0oVkoA?pwd=t16q

Once downloaded, place the checkpoints in the appropriate directory within this project.

🚀 Usage

To generate the results corresponding to the figures in the paper, run the following scripts:

Figure 1: Execute E1_TokenAlign.py
Figure 2: Execute E2_TokenAlign2.py
Figure 3: Execute E3_TokenAlign2-drop.py
Figure 4: Execute E4_VQTTAlign_emotion.py

📂 Repository Structure

E1_TokenAlign.py: Script for reproducing the results in Figure 1.
E2_TokenAlign2.py: Script for reproducing the results in Figure 2.
E3_TokenAlign2-drop.py: Script for reproducing the results in Figure 3.
E4_VQTTAlign_emotion.py: Script for reproducing the results in Figure 4.
